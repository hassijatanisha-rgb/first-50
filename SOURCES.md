# Editorial sources and production notes

First 50 is a collection of original short-form explainers. The scripts summarize widely documented concepts and add original framing, examples, diagrams, and commentary. The movie, book, and anime entries do not contain excerpts, screenshots, character art, soundtrack audio, or footage from the works discussed.

Selected reference starting points include Encyclopaedia Britannica, NASA, the American Psychological Association, NIST, PubMed-indexed literature, Project Gutenberg for public-domain texts, and official publisher or studio reference pages. References were used for fact checking; wording and visual treatment are original.

Narration is locally synthesized. See `ATTRIBUTIONS.md` for the exact engine, model, checksum, and rights record.
