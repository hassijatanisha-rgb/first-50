# First 50

Fifty original vertical video explainers across science, psychology, books, movies, and anime. Every video includes an original script, custom motion-card visuals, synthetic narration cleared for publication, a downloadable caption, and a readable transcript.

This repository is the public GitHub Pages release artifact. Production scripts and build intermediates are maintained separately.
